# Herky Steakhouse — Photography Rebuild

Built from the existing 2.2 homepage working draft, preserving all 16 pages, styling, scripts, and navigation.

## What changed
- All 10 homepage carousel slides now use **different, locally bundled** generated photos.
- The existing downtown building concept is retained in the same fourth slide position; its image is included at `assets/herky-building.png` for self-contained deployment.
- Feature cards, featured dishes, and the Come Hungry / Leave Happy banner use matching Herky photos.
- Other external Unsplash `<img>` references were replaced with local generated imagery where applicable.
- Assets are optimized JPEGs, and images work without external photo hosts.

## Deploy
Upload the files **and the entire assets folder** to the repository root. Keep the `assets` folder name unchanged.

All restaurant services are fictional demonstrations.
